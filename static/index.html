Browser and network access

Stored in Switchyard's persistent internal database; changes apply immediately. LAN IPs work without manual configuration. Public HTTPS hostnames use password authentication; MFA is optional and is enforced only after verified enrollment.

Persistence

SQLite assets, audit records, host trust and Bitwarden CLI state live in your persistent Docker volume under /data. Remote tmux sessions are maintained on each destination machine.

The backup contains a live SQLite snapshot and trusted host keys. Sessions, private SSH keys, Vaultwarden CLI cache and bootstrap secrets are intentionally excluded. Keep this file protected; it includes password hashes and asset metadata.
